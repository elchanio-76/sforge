## CLI ↔ MCP inventory

`parity.test.ts` runs each mapped row through `--json` and through the tool on identical copies of
a fixture and compares the data (times, paths and ports normalized), the error code, the hint and
the files left behind. The drift guard fails when a command has no tool and no reason, a tool has
no command, or an option has neither a parameter nor a reason.
