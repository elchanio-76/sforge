# @staticforge/theme-default

The accessible default theme of [staticforge](https://github.com/elchanio-76/sforge): layouts for pages, posts, lists, tags,
search and the 404 page, with light and dark color schemes, visible focus, and no JavaScript
except on the search page.

staticforge uses it when the config says `theme: "default"` (the default). To make your own
theme, copy this package's files and see [the theme contract](https://github.com/elchanio-76/sforge/blob/main/docs/content/themes.md).
