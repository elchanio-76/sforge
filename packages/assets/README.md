# @staticforge/assets

Image, script and stylesheet processing and search indexing for staticforge builds.

This is an internal package of [staticforge](https://github.com/elchanio-76/sforge), published so that the
[`staticforge`](https://www.npmjs.com/package/staticforge) command-line tool can depend on it. Its
API can change in any release: install `staticforge` instead.
